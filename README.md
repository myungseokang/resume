# 강명서 · Product Owner

DevResume을 바탕으로 경력·프로젝트 본문을 넓힌 한국어 HTML 이력서입니다. 정적 파일만으로 동작하며 빌드·패키지 설치가 필요하지 않습니다.

## 로컬에서 보기

```sh
cd ~/workspace/resume
python3 -m http.server 8837 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8837 을 엽니다.

## 편집할 파일

- `index.html`: 프로필·경력·프로젝트·학력.
- `main.css`: 한국어 타이포그래피, 반응형 레이아웃, A4 인쇄 스타일.
- `main.js`: 브라우저 인쇄 / PDF 저장 버튼.
- `assets/css/devresume.css`: 원본 DevResume / Bootstrap 스타일. 커스텀 스타일은 `main.css`에서 관리합니다.
- `CNAME`: 기존 커스텀 도메인 `resume.myungseokang.space`.

## 구성

경력 요약 → 대표 성과 → 에이블리 PO 담당 이력 → 대표 프로젝트 3개 → 핵심 역량 → 이전 개발 경력 → 학력·활동.

대표 성과의 합산 범위, 실험의 상대 변화와 %p 차이, 신규·복귀와 기존 사용자 결과를 구분합니다. 개발 경력·학력·연락처는 기존 사이트 내용을 유지했습니다.

## 공개 수치 마스킹

매출·MAU·DAU·실험 결과의 실제 수치는 HTML 소스에서도 `비공개`로 대체했습니다. 원수치가 포함된 검토 문서와 화면 캡처는 이 저장소에 포함하지 않습니다. 재직·프로젝트 기간과 지표 정의(D+3, 2개 이상 제품 참여 등)는 유지합니다.

## 확인할 항목

- 데스크톱과 모바일에서 제목·연락처·표가 잘리는지.
- 성과 요약과 목차를 누르면 해당 경력·프로젝트로 이동하는지.
- 키보드 탐색, 이메일·외부 링크, 프로필 이미지가 동작하는지.
- 인쇄 / PDF 저장에서 A4, 브라우저 머리글·바닥글 끄기 기준 페이지가 나뉘는지.
- 게시 전 원고와 회사 지표의 공개 범위를 최종 확인했는지.

기존 GitHub Pages의 배포 소스는 `master` 브랜치의 루트입니다. 해당 브랜치에 push하면 `resume.myungseokang.space` 사이트가 갱신됩니다.

## 이번 버전의 검증

2026-10-18 로컬 브라우저에서 320·390·768·1280px 화면을 확인했습니다. 가로 넘침, 내부 앵커 누락, 이미지 로딩 실패, 브라우저 콘솔 오류는 없었습니다. HTML·CSS·JS·프로필·favicon의 HTTP 응답과 JavaScript 문법·Git 공백 검사도 통과했습니다.

인쇄 버튼이 브라우저 인쇄를 호출하는 것까지 확인했습니다. 앱 내부의 네이티브 인쇄창 접근 제한으로 저장된 PDF의 페이지 구분은 검증하지 못했습니다.
